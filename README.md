# ANN-Optimized-with-PSO-for-Prediction
Neural network optimization using Particle Swarm Optimization (PSO) for predictive modeling, evaluating multiple architectures and optimization strategies to improve regression accuracy on real-world data.

# Overview
This project explores the use of Particle Swarm Optimization (PSO), a bio-inspired optimization algorithm, to improve the performance of neural networks for predictive modeling. The study focuses on optimizing neural network parameters and evaluating different architectures to enhance regression accuracy on real-world data.

Traditional gradient-based optimization methods can sometimes struggle with local minima or inefficient parameter tuning. PSO provides an alternative approach by simulating swarm intelligence, allowing the model to search the parameter space more effectively.

The results demonstrate how bio-inspired optimization techniques can improve neural network training and predictive performance.

# Methodology
Data Preparation
The dataset was preprocessed through cleaning, normalization, and splitting into training and testing sets.

Neural Network Model
A feedforward neural network was implemented for regression tasks, with experiments conducted across different architectures.

Particle Swarm Optimization (PSO)
PSO was applied to optimize neural network parameters by iteratively updating candidate solutions based on swarm intelligence principles.

Model Evaluation
Model performance was evaluated using regression metrics including MSE, RMSE, MAE, and R² score to assess predictive accuracy.
